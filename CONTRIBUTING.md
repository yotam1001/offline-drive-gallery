# Contributing

Bug reports and focused improvements are welcome. Please describe the Windows version, the file type, what happened, and how to reproduce it without sharing private file names or thumbnails. For thumbnail issues, say whether Explorer shows a thumbnail for the same file.

Run `dotnet test OfflineDriveGallery.slnx -c Release` before submitting a change. Keep scans read-only, preserve the previous catalog on cancellation or incomplete scans, and add a test when changing catalog behavior.
